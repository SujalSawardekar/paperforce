# Project Instructions & Permanent Guidelines

This file serves as the permanent instruction set for every task in this project.

## Core Rules & Workflow

- **Document Verification**: Always read the PRD, Architecture Document, Design System, Rules Document, Development Phases Document, and Memory Document before making changes.
- **Source of Truth**: Treat the PRD as the primary source of truth.
- **Architecture Alignment**: Follow the Architecture Document for folder structure, routing, components, and project organization.
- **Design System**: Follow the Design System for colors, typography, spacing, UI components, animations, and overall visual language.
- **Coding Standards**: Follow the Rules Document for coding standards, error handling, accessibility, performance, and AI boundaries.
- **Phased Execution**: Follow the Development Phases Document and complete work phase by phase.
- **Memory Document Updates**: Always read and update the Memory Document after every completed iteration.
- **Component Preservation**: Never regenerate completed components unless requested.
- **Component Reuse**: Reuse existing components whenever possible.
- **Code Quality**: Keep the code modular, scalable, and production-ready.
- **Minimal Dependencies**: Do not add unnecessary libraries.
- **TypeScript Strict Mode**: Use TypeScript strict mode and maintain clean code.
- **Responsive Layouts**: Maintain responsive design across all breakpoints.
- **Performance & SEO**: Optimize for SEO, accessibility, and Core Web Vitals.
- **Smooth Animations**: Keep animations smooth, hardware-accelerated, and purposeful.
- **Minimal Ambiguity**: Ask for clarification only when a requirement is genuinely ambiguous.
- **Direct Implementation**: Unless requested otherwise, proceed directly with implementation instead of providing long planning explanations.
- **Dependency Awareness**: Never overwrite existing functionality without understanding its dependencies.
- **Documentation Integrity**: Update documentation whenever the project structure or implementation changes.
